# Vindicator Model Plan

## 0. Layered architecture

```
Claude            = reasoning / agent (never the prediction model)
MCP + adapters.py = data access
Python engine     = prediction (Elo, Dixon-Coles/Poisson, xG features, ML)
Data layer        = API-Football (backbone) + TheSportsDB (badges/player art)
                    + Football-Data.co.uk CSVs (training) + football-data.org
                    + OpenLigaDB + Sportmonks free tier (xG pilot leagues)
Market layer      = bookmaker odds via API-Football (+ dedicated odds API later)
Value engine      = model probability vs de-vigged market price → EV > Edge > CLV
Benchmark         = Opta-Supercomputer-style Monte Carlo (league/tournament
                    probabilities) + Forebet-style per-market tables for UI
```

**All outputs are percentages**, never bare picks: every scoreline gets a
probability (e.g. 2-1 = 17%), every market a % split.

## 1. Prediction engine — ensemble of 5 models

Each market section on the site can be generated by any of these models; the
admin picks per-section via dropdown (see §3). All models output calibrated
probabilities per market, which are converted to fair odds (1/p).

| # | Model | What it does | Strength |
|---|---|---|---|
| 1 | **Dixon-Coles Poisson** | Time-decayed attack/defence strengths per team → full scoreline probability grid | Exact score, O/U, BTTS, 1X2, handicaps — the backbone |
| 2 | **Elo (club-level, home-adv adjusted)** | Rating difference → win/draw/loss probabilities (Davidson draw model) | Robust in lower leagues with thin data; seeds from ClubElo-style ratings |
| 3 | **Calibrated LightGBM** | Gradient-boosted trees on engineered features (rolling xG, shots, form, rest days, odds movement), isotonic/Platt calibrated | Best raw accuracy where data is rich (top leagues) |
| 4 | **De-vigged bookmaker consensus** | Strip the margin from closing/current odds (proportional + Shin method) → market-implied probabilities | "What does the market think?" section; hardest benchmark to beat |
| 5 | **Ensemble (meta)** | Logistic stacking of models 1–4, weights fit per league tier | Default model for the public site |

Notes:
- Performance-quality style adjustments (schedule strength, minutes-weighted
  player availability) enter as LightGBM features, not a separate model.
- Player markets (top scorers/assists, shots) use per-player Poisson rates
  scaled by expected team goals from the Dixon-Coles grid.

## 2. Markets generated per fixture

1X2, double chance, BTTS, over/under (0.5–4.5), Asian handicap, exact score
(top 10 scorelines), total shots, total goals, xG comparison, top scorer /
assist candidates, market view (de-vigged odds), bookmaker suggestion
(value edge = model prob − market prob), timestamped odds snapshots.

Each record carries: `match_id`, `market`, `model`, `timestamp`, probs, fair
odds, book odds, and later the settled result.

## 3. Admin model selector

WP admin screen (custom plugin page): for each section (BTTS, O/U, 1X2, exact
score, shots, scorers, market view) a dropdown choosing model 1–5 + "hide
section". Stored as WP options; the display layer reads the option and renders
that model's numbers from the latest predictions payload.

## 4. Tiers and league access

- League tier map: T1 (top-5 leagues + CL/EL), T2 (second divisions, other
  UEFA top flights), T3 (lower leagues, cups elsewhere).
- Member ranks gate access *upward*: new/free members see lower-league (T3)
  predictions; higher ranks unlock T2 then T1 and extra markets (exact score,
  handicaps) and earlier prediction release times.

## 5. Points economy & game

- Users build **Top 5 players + Top 5 teams** rosters; weekly scoring from
  real performances (goals, assists, clean sheets, results).
- Users also make their own match predictions; points awarded by a proper
  scoring rule (Brier-based: `points = round(k × (0.25 − brier)/0.25)`) so
  confident-and-right beats lucky guesses and hedging.
- Points → rank → unlocks better model output (see §4) + reward redemptions.
- Leaderboards weekly/monthly/season; rewards catalogue redeemable with points.
- No real-money wagering. Odds are informational; visible disclaimer that
  predictions are not betting advice.

## 6. Evaluation ladder (in order)

1. **Brier score** per market, rolling 50/200 predictions, vs. de-vigged
   market baseline.
2. **Log loss** (punishes overconfidence harder) — same comparisons.
3. **Calibration** — reliability diagrams per probability decile; recalibrate
   (isotonic) when a decile drifts > 3–4 points.
4. **ROI / CLV** — paper-trade flat stakes on value edges > threshold; track
   closing line value. Positive CLV is the promotion gate for any model
   change reaching the public site.

Settlement job appends results + eval metrics to `records/model-history.jsonl`
after each match; a weekly report aggregates the ladder per league tier and
per model, and drives ensemble reweighting.

### Free, terms-compliant data sources

| Source | Role |
|---|---|
| API-Football (free → Pro/Mega) | Backbone: fixtures, live, lineups, injuries, odds |
| TheSportsDB | Badges, player photos, stadium art |
| Football-Data.co.uk | Historical results + closing odds CSVs (training) |
| football-data.org | 12 top competitions cross-check |
| OpenLigaDB | German leagues, fully open |
| Sportmonks free tier | Danish Superliga + Scottish Premiership with xG/predictions — rich-data pilot |
| StatsBomb Open Data | Event-level xG training data |
| ClubElo | Elo rating seeds/validation |
| FootyStats API (free tier) | BTTS/over-under aggregate stats — verify current free limits |
| Understat / FBref | xG scrape-tolerated, historical training only, rate-limited, non-commercial care |

Not used (no legit API / ToS forbids): bet365, Sofascore, FotMob,
Transfermarkt, BetExplorer, Opta Supercomputer (benchmark inspiration only).

## 7. Pipeline

```
cron (matchday: every 1–5 min; otherwise hourly)
  → fetch fixtures, lineups, odds, live scores (data API)
  → run models 1–5 → predictions.json
  → append to records/model-history.jsonl (git commit + push)
  → POST to WordPress REST endpoint (custom plugin) → site renders
  → post-match: settle, evaluate, append results
```

Front end: WordPress + Bricks (NovaMira Pro), custom plugin exposing
shortcodes/elements for fixture cards (badges, player photos from the data
API), live score ticker (polling JS), odds tables, leaderboards; GamiPress (or
custom) for points; WooCommerce for invoices if payments are added later.
